## 第一版

单仓库 Python＋pytest Bug 修复：记录失败和修正 → 隔离验证 → 结构化经验 → 相似任务应用 → 反馈、修订和停用 → 最小经验面板。

经验附带来源、代码与依赖条件。修复验证通过只证明来源修复有效；产品收益必须在未见任务上另外评价。允许没有合适经验时不注入。

## 本地开发

需要 Node.js 24.10+、Git、Python3.10+ 和 pytest9.1.1。安装项目依赖后执行检查：

```sh
npm ci --ignore-scripts
npm run check
```

本机没有 npm 时，可在本地临时目录使用 npm 官方分发包；这不是项目运行依赖。验证只在明确受信任的仓库执行项目代码。源修复必须已有前后两个 commit；未提交修复先保留候选。详细边界见 [T002验证记录](docs/development/T002-pr.md)。
