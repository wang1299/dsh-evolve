# T004 本地 PR 提案：本机面板与闭环演示

本地任务T004；基线2fd39ced208add4fae27bfdce0104be1dc8e1f7f；分支codex/mvp-panel。远端Issue/PR未创建。

实现loopback最小面板，展示经验、任务、来源报告、版本和反馈；支持revision保护的修订、停用、恢复和追加反馈。数据API需要随机token，写入检查Origin、JSON和Host，页面CSP和textContent避免跨站和插入内容执行。令牌不发给Agent，不开放任意文件或命令入口。

`npm run demo` 创建全新合成Git仓库、独立pytest验收、失败与修复commit，验证来源后将经验提供给另一项显式任务，再记录unknown反馈和停用。输出在忽略的`.probe-work/`；不上传私人数据，不将合成任务当真实Agent收益。

`node dist/src/cli.js panel --config <demo目录/config.json>` 显示本地私有访问链接。用户可看完整例子，或配置自己的受信任仓库。正式DSH内前端槽位尚未实现，当前是共享同一SQLite的独立本地面板。

验证：HTTP集成测试覆盖未认证读取、跨站写拒绝、修订冲突和恢复候选；浏览器已核对来源与历史展示，并实际恢复历史为v4候选，确认不会自动变成已验证。根据实际浏览器检查将原始JSON收拢到可展开记录，默认显示简明结果。真实模型任务和效果对照未运行。
