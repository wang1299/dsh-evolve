# T019：自动任务证据与最小后台机制

Issue [#47](https://github.com/wang1299/dsh-evolve/issues/47)，基线`30ed2139e11f065c43722e19662fefcf7622a663`，设计[ADR022](../decisions/022-task-evidence-jobs.md)、任务[T019](../tasks/T019-task-evidence.md)。源码/验证/最终合并状态见关联PR，不以历史检查代替当前头。

## 已实现范围

- 原六工具/Task格式保持。finish在同一事务关闭任务并唯一入队；同任务重复结束不重采，idle/Agent自评不触发验收。采集仅同任务最小纠正/验证引用、事件元数据、固定commit/依赖及有界Python diff；不读完整聊天、任意工具输出或凭据。
- SQLite v4 Job/Attempt/Bundle和来源保留外键；条件领取、随机token/lease、最多3次安全本地恢复、原子发布和陈旧worker拒绝。验证开始标记落库后中断为unknown，不自动重开。DSH bind与CLI面板管理worker生命周期；核心显式runNext，没有隐式常驻线程。
- backgroundVerification默认false。须另开且已有executionTrusted、策略/当前版本仍匹配，才可无候选前置地调用现有Git/pytest验证。已有匹配报告取冻结输入中的最新一份，不能用旧成功掩盖新失败。没有用户纠正不编造，修正可由版本和失败→通过证明。
- 面板显示Job、包、来源、缺口与Attempt；不开放HTTP提权/重试。ready仅为后续提炼的材料条件，不新增/启用经验，也不证明自然语言正确或收益。

## 格式、保留与限制

v2/v3原JSON/历史不改，v1沿用原有报告降级迁移；v4事务创建新表，旧程序拒绝v4，不能混跑/直接降级。queued及历史包的来源由外键固定；清理可删除原事件及真正未引用的来源，但包输入有意保留最多128条元数据、32条来源引用、8000字符去敏Python差异，总输入≤128KiB。超限/非法旧事件按完整记录省略并标不完整，不能伪称完整采集。

Job/包不回填历史已关闭任务，不从工具运输错误推断pytest失败或用户纠正；验证采用现文件隔离，不是恶意代码沙箱，进程后代/总deadline仍G08。旧前台verify不变，不因后台Job存在而宣称所有异步操作已有耐久恢复。未做容量实验、通用LLM提炼/外部付费资格、自动上下文交付或真实模型收益。

T011/T015/T017预算、unknown与一次资格不改；本轮无模型调用/真实凭据或私人会话读取，无npm/Release/部署/权限更改。本机既有DSH预览未自动更新，父#8/#15和协议#34保持open。
