# T018：standard服务档位兼容的离线验收

Issue [#45](https://github.com/wang1299/dsh-evolve/issues/45)，实施前设计[ADR021](../decisions/021-standard-service-tier.md)，任务[T018](../tasks/T018-standard-tier.md)。本轮没有真实模型调用、凭据访问、新付费资格或实际实验账本。

## 修改与依据

新增显式`t018-standard-tier-v1`解析策略及预算/回执身份。只在两个正常usage位置接受缺省或严格字符串standard，继承T015输入总量高水位/最终累计输出；其他未知字段/位置和无完整终结继续拒绝。不支持档位为有限原因unsupported_service_tier、usage/diagnostic均null，不保存档位值。额外未知字段诊断只包含真正未知名称指纹，不将已接受service_tier混入计数。

schema2/3与回执v2的policyId枚举扩展，新策略必须显式receiptVersion=2。旧两策略、默认v1、旧文件含义保持；v1不允许新身份/原因，新原因在v2也只允许新策略。旧程序会拒绝新身份，不能混跑/降级打开；没有迁移或历史费用重算。未知策略在目录/锁/账本写入之前拒绝。

T017只确认字段名，未保存值或完整SSE，因此合成standard流是文档分支测试，**不是原始真实响应重放**，也不证明已解决T017或历史T015。请求参数ignored与响应字段接受分别处理；依据链接及限制在ADR021。
