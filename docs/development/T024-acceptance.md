## 复现与修改

先提交设计与回归 4568d59。完全离线 loopback HTTP 客户端读完 `message_stop` 后主动取消响应体，上游仍保留待完成的响应；旧转发器立即取消上游，断言 `true !== false` 失败。

修复把下游断连与上游 EOF 分开：完整且有效终端帧后继续在既有截止时间/字节上限内排空；没有有效终端帧则仍立即取消。收到终端帧只允许排空，不能直接结算；全部上游 EOF 后仍执行严格判定和回执持久化。已断开的下游不再写入。
