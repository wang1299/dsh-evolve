# T028 用户界面验收

Issue [#65](https://github.com/wang1299/dsh-reforge/issues/65)，基线729cbf3。[设计ADR030](../decisions/030-learning-home.md)在实现前提交为1eb4c0b。发布状态：未发布；本次没有新增模型调用或上传真实学习数据。

## 问题复现与实现

原面板在正常选择经验后同时展示事实来源下拉框、长测试文本、版本编辑、停用/恢复及反馈字段；用户必须理解技术结构。原实现可在基线运行面板并选择候选复现。T028将HTTP服务和本地展示拆开，默认入口呈现学习动态和经验卡片，详情先呈现策略/适用范围/真实应用，证据与管理按需展开。

状态仍区分待检查、来源已验证及停用，应用仍称提供参考。来源验证和任务验收不是经验收益证明。任务名替代可见UUID；原始标识、修复证明、每条事实出处、修订和历史仍可展开。未知/失败/缺材料在首页提示，完整处理记录保留。
