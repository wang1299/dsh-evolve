# 方法依据与当前实现

核验日期：2026-10-18。方法借鉴不等于复现论文，也不证明本产品有收益。

## 已核实的研究对象

| 方法 | 优化对象与反馈 | 评价与本项目取舍 |
|---|---|---|
| [MemRL v2](https://arxiv.org/html/2601.03192v2) | 冻结模型，按语义召回与经验效用选择，利用环境奖励更新记忆效用 | 包含BigCodeBench等任务、无记忆/RAG等基线和迁移拆分。借鉴反馈驱动的选择；本项目没有实现其Q更新、embedding或理论假设。 |
| [GEPA v2](https://arxiv.org/abs/2507.19457v2)、[官方实现](https://github.com/gepa-ai/gepa) | 反思执行轨迹和自然语言反馈，生成、评价并组合提示候选；对象是提示/文本候选 | 论文对照其他提示优化和RL方法。当前不演化全局提示，不复制论文提升数字；先验证来源经验的适用与反例处理。 |
| [ExpeL v3](https://arxiv.org/abs/2308.10144v3) | 从积累任务提炼自然语言经验，推理时召回 | 说明经验提炼本身已有研究；本项目价值需由来源证据、版本约束、反例更新及独立实验体现。 |

## 当前策略（T008a，已实现，待当前PR验收）

- 输入：任务摘要、本地结构化经验、来源验证记录、当前仓库/代码/依赖指纹，以及精确经验版本的使用和反馈记录。
- 资格：排除候选、停用、来源证明不匹配、当前来源任务、代码或依赖不适用的经验。
- 文本分数：在合格经验上计算BM25（k1=1.2、b=0.75、标题频次权重2），`s=raw/(1+raw)`。查询词项去重，不按查询总长度扣分；至少两个内容词命中、至少一个标题词、s>=0.2。英文拆标识符/去固定功能词，中文相邻双字。参数和门槛是固定工程启发式，不是概率，也未用留出调参。
- 效用：每次应用取最新已知反馈，`u=(accepted+1)/(known+2)`；unknown不计成功。排序为`0.7*s+0.3*u`，最多提供一条，无合适项则空。
- 输出：经验内容、精确revision、选择原因与应用记录。记录只证明上下文被提供，不能证明模型遵循或因此成功。
- 负反馈：当前实际使用版本的rejected/counterexample触发停用；旧版本反馈保留历史，不停用后续修订。修订和恢复产生新候选并重新验证，不继承旧版本效用。

来源修复是否有效由独立pytest输入的失败/修复/回归结果判断。后续应用结果目前由使用者追加；没有把Agent自报完成自动转换成accepted，也没有在线因果归因。

旧版的任务词元命中比例0.15保留为离线消融及历史评价策略；当前普通经验检索也使用相同BM25，不执行来源/作用域/效用筛选。策略摘要已版本化，旧实验仍可评价，禁止同一组混合策略。实现前设计、方法来源、冻结数据和全部失败见[ADR009](decisions/009-retrieval-coverage.md)及[离线诊断](evaluation/retrieval-v1.md)。合成留出仅召回从5/9到6/9，误选仍3次，不能说明真实任务收益。

## 数据需求、评价与限制

一条来源修复只能验证数据闭环；效用没有固定的最小训练量，零反馈时为中性先验，少量反馈不支撑普遍结论。文本匹配可能漏掉同义任务，人工反馈可能有偏，固定文件指纹可能拒绝本可泛化的经验，选择后的结果有选择偏差。

下一阶段先固定小规模真实任务集，按任务族拆开积累与未见评价，每项任务三组配对并重复，报告每个指标的已知/未知样本和所有失败。预算不足时缩小实验并标记初步；不从合成来源案例计算Agent收益。完整协议见[评价说明](evaluation.md)。是否采用embedding、上下文效用或提示搜索，由误召回/漏召回及三组结果决定。
