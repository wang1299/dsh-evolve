# DSH-Reforge v0.1.0-alpha.1

首个实验性公开版本：从有测试依据的 Bug 修复中积累结构化经验，在后续适用任务中提供参考。

## 内容

- 正常对话的有限采集与私有代码快照，来源修复重放、自动候选提炼和独立再验。
- 代码/依赖范围检查、相关经验选择、反馈、修订、停用与历史。
- DSH 原生插件详情、对话入口和主题跟随；保留独立面板。
- 包名/CLI 改为 `dsh-reforge`，兼容旧配置变量、SQLite v9 和 `evolve_` 工具。仓库保留原地址。

## 安装

需要 Node.js ≥24.10、**DSH 0.2.0-rc.2**；测试验证需要 Git、Python ≥3.10 和 pytest。执行：

```sh
dsh plugin --profile web add dsh-reforge@0.1.0-alpha.1
```

使用同一 profile 重启 Web，从「插件 → dsh-reforge」打开。学习默认关闭，配置与旧本地包迁移见 [安装指南](https://github.com/wang1299/dsh-reforge/blob/v0.1.0-alpha.1/docs/installation.md)。不要安装 registry 上其他项目的 `dsh-evolve`。

## 验证与限制

代码、双平台 CI、固定官方服务兼容、实际安装和独立只读 AI 评审的执行结果见 [T033 验收](https://github.com/wang1299/dsh-reforge/blob/v0.1.0-alpha.1/docs/development/T033-acceptance.md) 及 [Issue #75](https://github.com/wang1299/dsh-reforge/issues/75)。来源验证不等于未来收益；已有小规模任务对照未观察到成功率改善。当前第一版聚焦单仓库、受限 Python＋pytest，独立验收需要所有者配置，本地代码执行不具备强沙箱。自动提炼次数不是整个 DSH 的金额硬限；未知调用保留，不自动重试。

附件 tgz 下载自此版本的 npm registry 并经过完整性核验；`SHA256SUMS` 和 `release.json` 记录制品字节与源提交。源码 tag 绑定相同 npm SHA512/SHA1 和发布者。仓库历史记录仍使用原 DSH-Reforge 名称。
