# ADR030：以学习动态为入口的用户界面

日期：2026-10-20；T028 / Issue #65；实现前决定，基线729cbf3。

## 问题

当前面板把事实绑定、版本编辑和后台处理一起呈现，要求用户理解工程内部结构。用户希望看到经验的内容和实际使用情况，正常操作不应要求识别UUID或拼装来源。

## 信息层级

1. 默认首页“学习动态”：简短价值说明、可参考/待检查/提供参考的真实数量、近期经验和后续任务收到参考的动态。空库解释起点；等待、缺材料和未知结果提供可读状态。
2. “经验”提供搜索和状态筛选。卡片展示原始标题、策略摘要、状态及来源任务，点击进入单页详情。
3. 详情先展示处理方法、适用文件、验证状态和后续应用。事实与测试证据、人工管理、历史和技术标识按需展开；不在首屏呈现来源选择器、原始JSON或修订表单。
4. 反馈使用任务名称，选择结果后仍须明确提交。保留accepted为任务通过验收的语义，不改成因果“有帮助”；不相关/无效/反例继续沿用原停用规则。成本和返工可选展开。
5. “处理记录与本地数据”提供原后台详情、诊断和清理入口。未知、失败不能仅靠收起而消失：首页必须提示未完成的学习，并可进入详情。

## 边界与刷新

仅重组HTML、CSS与浏览器展示代码；HTTP契约、SQLite v8、七个DSH工具、授权、验证和经验生命周期不变。候选不会因界面改版自动启用。首页不声称自主识别任意错误、已避免错误或已提升Agent效果。

后台轮询只更新列表与动态，不重建已打开的编辑区域、不丢失草稿或抢焦点。显示连接失败及数据陈旧状态；写操作仍使用用户打开时的revision，冲突明确提示，不能悄悄改用新revision。候选变化同样不自动运行模型或测试。

来源文字与模型建议一律作为不可信文本，用textContent构造；不使用innerHTML。保留nonce CSP、认证、同源、Host及请求长度保护。不引入外部字体、脚本、统计或前端依赖。

## 验证

保留现有认证、同源、来源校验与409测试。新增针对首屏层级、真实用户操作和轮询草稿保留的回归。使用隔离合成库进行实际浏览器桌面/窄屏与空库/非空库检查，覆盖长文本、危险字符串、反馈、停用恢复及冲突。截图和本机运行材料不上传真实用户数据。

自动登记任务、失败修复归并及后台验证资格是后续独立任务。本设计改善呈现，不代表自动学习体验已完成。
