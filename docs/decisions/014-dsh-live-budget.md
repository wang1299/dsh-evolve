# ADR-014：DSH真实模型闭环的请求预算边界

2026-10-19，T011 / Issue #31，基线52ed030。用户指定DeepSeek官方、真实DSH闭环、本轮累计人民币5元；Key已由用户保存在独立测试DSH的本机凭据服务。本任务不发布，不更改账户或账单。

## 决定

1. 使用完整独立发行宿主DSH 0.2.0-rc.2的官方SDK profile及真正Agent loop，安装本项目实际tgz。新测试profile与Web预览分开；凭据仍由宿主读取同一私有文件，脚本不打印、复制或写入Key。只发送新生成的合成代码、任务和经验，不导入已有对话。
2. 本次以sdk-minimal为模板，禁用任意shell工具、Session log远端扩展及包库存扩展，增加官方本机凭据服务和本项目插件。模型只能使用插件六工具并返回修复提案；宿主限定目标文件、校验代码结构后写入并commit。外部pytest目录不交给模型写。不是普通Web全工具自主开发或强沙箱验证；记录人工提示和宿主协助。
3. 所有模型HTTP请求经过临时loopback代理，代理只向固定官方https://api.deepseek.com/anthropic/v1/messages转发，禁止重定向、Files/搜索/其他路径和模型；只接受deepseek-flash、stream=true、max_tokens≤4096的纯文本工具会话。请求≤256KiB，响应≤1MiB，60秒期限，最多16次。无自动实验重跑；适配器重试关闭，即使有额外请求也必须重新计账。
4. 预算账本以微人民币整数保存。本轮唯一账本.probe-work/t011-budget.json，独占锁；每次在网络发送前持久化最坏预留。根据官方当日Flash高峰价输入2元/百万、输出8元/百万，输入按1,100,000 tokens保守覆盖官方1M上下文（含1048576表示），每请求预留2,232,768微元。只在完整message_start/usage、message_delta最终usage与message_stop且连接正常结束后，按所有输入（缓存也按未命中）和输出的高峰价结算。用量缺失、超界、流中断、HTTP失败或进程崩溃保留全部预留；预留额不得因重启恢复，失败不等于免费。已消费+活动/未知预留永不超过5,000,000微元。与服务商最终账单分别报告，不声称可锁定未来价格/服务端版本。
5. 同时只转发一个请求，账本持久化先于fetch，重新启动保留未结算资格；预算不足或并发请求拒绝。实验计划也以独占创建防止同一计划重复调用。任何分阶段异常保留partial/unknown，不能靠新输出目录重置预算。
6. 来源任务先让真实Agent开始任务、记录明确纠正、返回代码提案；宿主提交后，同会话引导候选、来源验证、凭据引用和finish。只有实际source_verified且事实来源完整才继续相似任务。随后创建同仓库新合成错误、新会话，实际begin返回的精确经验版本和模型后续提案分别留证，独立pytest判断目标修复。反馈由宿主在独立验收后注明合成基准来源，不授予模型owner反馈权限。
7. 这是有人工提示的集成实验，不是新三组收益对照，不改写既有v1/v2/v3配方或结果，不声称自动提炼已实现。工具/阶段/验收/成本逐项报告；idle仅用于等待，正确性由pytest证明。原始事件、凭据、配置及报告仅本机ignored；公开文档仅去敏统计/摘要。

价格依据：[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，2026-10-19核实；模型容量依据[官方模型列表契约](https://api-docs.deepseek.com/api/list-models/)。官方未提供本任务可依赖的付费硬限接口，采用请求前最坏预留；若价格/容量不再满足该假设，停止调用并更新设计。

## 必要验证

实施前提交设计及失败测试。离线覆盖实际HTTP边界、并发/预算/未知状态、跨重启、不合法请求/重定向和SSE用量，零网络/真实Key。稳定代码先独立只读评审，再live一次；失败保留，不追加调用追求正结果。最终源码/文档与去敏结果复审、当前头两平台CI和仓库规则满足后squash。
