# ADR032：学习进度中心与独立面板收尾

2026-10-21，T030 / Issue #69；基线 acf892a，实现前设计。

## 决定

在认证的 `/api/state` 中追加 `learning` v1 只读投影：当前模式、前置配置检查、当前提炼逻辑次数余量，以及最近请求/任务的四阶段进度（记录变化、验证修复、提炼经验、独立复核）。只从既有任务、片段、证据包、提炼和经验版本派生，不新增数据库表或重写旧状态。配置齐备、面板连通、来源通过和未来收益分别描述。

每条进度严格关联任务、当前证据 Job 与其最新提炼链。历史失败不覆盖新任务；旧授权未知占额不释放。中断、无变化、材料不足、版本漂移、调用资格不足、模型暂不可用及候选被修改均给出固定中文原因和下一步，不展示原始异常、绝对路径、grantId 或模型凭据。未知或失败不提供自动重试按钮。状态阅读不执行命令、不创建 Job 或消耗授权。

面板主页首先显示学习是否开启及当前配置检查，再展示近期处理进度与经验卡片。候选可直接进入经验详情，完整证据/技术记录继续按需展开。轮询不替换未保存的编辑；新的只读区域不增加写入、开启或授权接口。

## 后台协调

CLI panel 已启动证据 worker 和无模型端口的提炼 worker；补充启动既有 `AutomaticLearning.start()`，使同库已授权自动片段产生的候选可继续独立验证。沿用策略摘要、归属、活动捕获排斥、版本/出处、执行信任及一次资格检查。关闭 CLI 时先停止协调及其他 worker，再关闭库。不开启关闭的自动模式；不为显式任务候选增加自动验收；不重跑 unknown 或新增提炼资格；不引入模型端口。

配置状态只说明本次面板进程加载的配置，不推测另一 DSH 进程是否在线或采用同一配置。独立面板不能提炼；等待模型时提示保持对应 DSH 宿主运行。未来可用独立 ADR 增加原生 DSH 前端、宿主心跳及配置向导，本次不伪造这些能力。

## 验收

先补失败回归，再实现：真实 CLI 子进程从已有候选完成来源独立复核；关闭/unknown 不推进；额度与用户 HEAD/index 不变。投影覆盖任务归属、当前授权余量、提炼链、候选修改/停用及固定失败原因；界面覆盖空态/进度/焦点/未保存编辑/窄屏。执行类型、静态、完整测试、兼容、实际包/原生脚本演练和独立只读评审，最终头双平台 CI 后才能合并。零新增真实模型调用，不声明质量或收益改善。
