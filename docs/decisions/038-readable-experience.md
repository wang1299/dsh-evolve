# ADR038：以问题、提醒和后续参考组织经验页面

2026-10-23，T039 / Issue #91。实施前决策，基线 `797e8f261ceb76800caab146ddcf989745e25ff2`。

用户实际体验后指出，原始策略、计数和状态更像后台信息。沿用 ADR030 的共享展示边界，将现有数据只读投影为用户可读的故事，不修改学习事实。

1. 默认卡片以已有来源任务说明“当时在处理什么”；详情依次说明当时的任务、留下的提醒和后来提供参考的任务。现有中文摘要优先，明确尾部英文检索词可只在短标题中收起，原始文字始终可展开。所有内容仍通过文本节点显示。
2. 中文提醒只来自该经验实际引用的明确纠正或已有中文策略，标明来源；不把纠正等同于策略翻译或模型已理解。没有中文时如实标示，处理方法原文保留。不开启模型翻译，不静默修订旧经验或生成业务示例。
3. 修复验证用可读状态对比展示已有报告。失败、跳过、超时、缺失或未知不能变成通过；数量、命令、版本、出处及原文放在展开层。来源检查只描述当时的修复，不表示当前可用或未来收益。
4. 后续记录只说明曾提供参考；是否被采用、是否改善结果仍未知。用户反馈的验收结果只按其原始语义呈现，并保留精确历史版本。候选、停用和等待确认显眼可辨。
5. 只修改共享展示和只读投影，HTTP/RPC、SQLite v9、模型输出契约、授权和生命周期保持。草稿/焦点、轮询、revision 冲突、未知写入不重试、CSP 与认证约束继续验收。任何将来持久化中文概述、翻译流程或新状态语义另作设计。

使用独立合成案例和隔离宿主预览，用户的冻结包、历史经验、私有快照、预算与授权保持。新版源码与可预览界面不等于已发布 npm 版本。
