# ADR 011：feedback-v1的真实模型初步对照

日期：2026-10-19。T008c，父#15/#8保持open。实现、调用前先固定本设计与protocol；不重用旧留出冒充新未见集。

## 范围和预算

用已有真实模型合成来源报告（本地SHA256 `36ef1b7891d3f2d976f1fc28c3d690448885cb87f6fdeaa663b547fb50961bee`）在新仓库重放并重新验证。固定[任务与验收](../../test/fixtures/feedback-protocol.json)，只上传新编写合成代码给当前CLI，不上传私人会话、真实用户仓库或凭据。

新调用总上限7：积累应用1次，两个转移任务各baseline/retrieval/evolve一次，共6次。每次gpt-6.1-sol/low，CLI0.163.0-alpha.10.2，HTTPS、provider重试0、90秒、工具事件上限0、宿主提示32KiB、输出1MiB。失败不释放资格、不中途换模型/任务/预算，也不补跑；温度、seed、服务端revision、token/金额硬限未知为null。总调用时间上限630秒加有界本地验证；不是金额硬上限或真实token相等保证。

先来源修复验证；再在积累任务中真正提供经验、调用模型并执行独立pytest。只有该应用通过，实验宿主才追加带verification ID的accepted，明确是基准验收反馈，不伪装用户原话或模型自报。积累失败就保留失败与未开始评价，消耗最多1次，不编造accepted。

评价任务不写反馈、不学习新经验。baseline不提供经验；普通retrieval仍为BM25原文；Evolve使用feedback-v1。该配方预期普通检索拒绝、Evolve从真实已接受应用备用表述召回；调用前检查预期差异，不能缩短/改写查询以追求结果。Evolve允许在正常产品里拒绝，此配方若无预期差异则保留准备失败、停止评价调用。

两个新写的合成目标属于相同“失败保留原映射”故障模式、不同函数/输入/验收；积累和评价ID/代码不同，但设计者知道题目，且目标刻意测试反馈词汇桥接。不是独立盲测、真实开源Bug基准或跨任务族泛化。只做一次重复，两个任务使用相反组序减少固定先后影响，仍不消除缓存/服务端采样偏差。

## 格式和实现

新增schemaVersion3，kind=codex-feedback-paired，复用v2任务/计划/运行契约，增加protocol摘要、固定调用预算、积累计划/实际运行/应用/反馈链及验证。v1/v2读入保持原样，新反馈配方只接受自己的policyDigest家族，不混淆旧bm25-v1。共享原子计划资格，另设protocol级本地一次性live资格；中断/失败不自动生成新目录再跑。

评价器必须拒绝：超过7次、积累未通过却写accepted/启动评价、反馈与应用/来源版本/任务/验收证明不一致、任务泄漏、未知/混用策略、冻结输入漂移、重复/缺失组、未完成冒称通过、伪造测试身份。各阶段均保留计划、实际启动、失败和unknown；phase1成本与6次评价成本分开并汇总，不只统计评价成功样本。

新运行前冻结全部提示/任务/源码/经验库/环境/外部验收摘要，检查宿主允许文件；每次由相同目标commit开始，修改只应用到允许文件。验收放在模型只读提案输入之外，不发给模型，包含失败前后相同测试身份及回归。CLI不能直接改代码，由宿主受限写入，不声称强安全沙箱或完整DSH模型循环。

原始源码提案、运行记录、数据库和完整证明只保存忽略目录.probe-work。公开文档只写去敏汇总、摘要、执行提交、实际指标及失败；不改写旧原始结果。默认/CI不调用模型，process fixture明确不是模型。先必要测试与稳定提交独立只读预审后再真实调用；若预审需修复，更新稳定提交后必要复审。

## 评价与限制

验收成功率同时给每组计划数/实际尝试数和已知数；记录测试失败复发、提供次数、模型usage、耗时。不能从“提供”证明模型采用，wrongExperienceApplied及人工返工/金额没有独立观测时保持null。两题全通过也可能没有成功率改善；原样报告无改善、回退、失败。来源验证通过不代替收益评估；#15/#8不因这次小实验关闭。

本机CLI与登录已核对，不读取/复制密钥。依据[官方结构化eval示例](https://developers.openai.com/blog/eval-skills)和[配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)核实JSONL/输出schema、推理及provider重试；官方控制不保证固定服务端权重/金额。本项目复用已审执行器，不修改CLI/账户/权限配置。
