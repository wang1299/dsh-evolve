# ADR-003：证据字段与追加反馈迁移

接受，2026-10-18，在实现迁移前记录。

独立复审指出首个本地实现的 schema v1 数据库存在 application_id 唯一约束，新代码的 CREATE IF NOT EXISTS 不会更新它；同时旧验证报告没有用例身份字段。

SQLite user_version 升为2，来源验证报告 schemaVersion 升为2。迁移在单个事务中复制反馈表到去掉 application_id 唯一约束的新表，核对并保留所有行；不删除用户学习记录。未知数据库版本拒绝打开。

旧验证报告保留原始字段和验收输入，补充空用例列表并明确标记需要重新验证；不能把缺失身份字段的旧成功报告继续当作有效证明。引用旧报告的当前 source_verified 经验新增 candidate 修订，保留旧历史和原验证关联。验证中断回滚整个迁移。禁用经验保持禁用。任务、应用、反馈ID保持不变。

验收：用旧建表语句创建v1数据库，放入报告和可应用经验，再用当前Store打开；旧反馈能够追加反例；经验已降为候选；旧版本仍可查看；重新打开幂等，无数据清空。
