# ADR 009：长任务检索与离线检索评估

日期：2026-10-19。范围为Issue #15的第一项交付T008a；父Issue #8和有经验暴露的模型对照仍未完成。

## 问题与选择（实现前记录）

v1相似度是查询命中词数/查询全部词数。增加与经验无关的操作约束可使原本相关的长任务低于0.15。只调整这个阈值会增加错误提供风险。

采用固定词项BM25作文本排序：`k1=1.2,b=0.75`，正IDF为`ln(1+(N-df+0.5)/(df+0.5))`，标题词频权重2，查询词项去重。排名分映射为`s=raw/(1+raw)`以与现有反馈效用组合；匹配至少两个不同内容词、至少一个来自标题，且`s>=0.2`。这三个拒绝条件是当前固定启发式，不是校准概率。英文拆camelCase和snake_case、去固定英语功能词；中文用相邻双字，不引入模型、embedding、同义词或域词典。重复词不制造额外查询权重。

来源/仓库/依赖/文件条件仍先过滤，再在合格集合计算BM25。每任务最多一条；效用与负反馈行为不变。选择原因保存方法版本、文本/效用分数和匹配词数，不保存额外会话数据。持久化结构和DSH接口不变。

普通检索对照同时采用相同BM25文本策略，只有Evolve执行资格过滤与效用；避免把较弱的旧检索当唯一对照。离线另保留v1全文覆盖及带资格过滤的v1两个消融。v2实验记录的policyDigest升级；评价器仍接受完整一致的旧策略实验，拒绝同一实验中同一组混用策略，不改写历史记录。

## 预先冻结的数据与验收

先提交作者编写的合成经验/查询/相关性标签，再实现算法。开发族：事务回滚、缓存键、路径边界；留出族：迭代器耗尽、时区转换、子进程管道。族间不共享问题、查询或经验；每族的来源经验与查询属于不同的描述场景。留出数据对开发者可见，只称预先冻结的合成任务族留出，不能称独立盲测、真实未见任务或模型收益。库存历史案例只可作为回归，不进入留出。

每族包含短/长正例、无关负例、词面冲突反例、版本不适用及无字面重合的语义正例。最后一项可能仍漏选；反例可能误选，均原样报告。先冻结数据摘要和策略，开发集之后才运行留出；看过留出后修改算法必须另开版本并将本留出转为开发数据。

报告四种策略的有效召回、错误提供、拒绝、输出字节、评分对数、实测时间，以及逐项结果/失败。离线资格标签是合成声明，不伪装可执行修复证据；真实来源/依赖/代码和停用仍用核心集成测试验证。零模型调用，无服务费用；时间仅描述当前机器，不能当普遍性能数字。

验收：长描述漏选回归在旧实现失败；新实现保留不相关/信息不足拒绝及资格边界；开发集有效召回改善且不增加错误提供，留出结果无论好坏都保留。必要类型/静态/核心/兼容检查、两平台CI、独立稳定提交评审后合并。有效模型收益与完整DSH应用安装仍归#8，不关闭#15。

## 方法来源和限制

[Stanford IR教材BM25](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html)给出词频/文档长度权重与常见参数，查询不按总长度归一化；[评估章节](https://nlp.stanford.edu/IR-book/html/htmledition/information-retrieval-system-evaluation-1.html)强调相关性标签和开发/测试分开。此处标题、拒绝门槛与效用组合是本项目工程选择，未复现论文结果。BM25无法理解否定、同义或跨语言；中文双字有限，经验库变动会改变IDF；来源正确不保证当前建议相关。需要更多人工标注和真实任务验证。
