# ADR018：独立追加预算的真实学习回归

状态：设计先行，2026-10-19。用户在原5元之外明确授权最多新增5元；T011的首次失败、资格及unknown占额不改写。仅本仓库，暂不发布。

## 决定

T015使用新固定路径`.probe-work/t015-live`、profile `evolve-t015`、`.probe-work/t015-budget.json`、单次live资格。计划记录新增5元、固定模型/SDK/提示/测试及安装、配置摘要；付费前检查摘要、原始合成Git版本和干净状态。已有plan/live资格不能覆盖或重新生成。预算不依赖启动目录，最多16个串行HTTP，无重试；未知仍全额占用，失败停止不追求成功补跑。

原T011账本schema1及严格逐项不下降策略保持。新增账本schema2明确`policyId=t015-snapshot-high-water-v1`，旧/新策略不能混开。每请求仍先持久预留2232768微元（110万输入×2＋4096输出×8），剩余额度不足就不发网。数值回执标注对应策略，完整流/持久化合格后才结算，回执不是账单；不根据旧SDK汇总回填。缓存按未命中高峰价计算，不依赖实际缓存折扣或空闲时段。

## 快照依据及保守性

2026-10-19核对[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：Flash输入未命中高峰2元/百万、输出8元/百万，版本DeepSeek-V4.1-Flash-1017、上下文1M。[DeepSeek兼容文档](https://api-docs.deepseek.com/guides/anthropic_api/)支持Messages流式；[Anthropic协议](https://platform.claude.com/docs/en/build-with-claude/streaming)说明delta用量累计。固定DSH0.2.0-rc.2官方适配器把四项非负输入/输出数值视为最新快照，并不要求缓存分项不下降。

新策略允许输入/缓存分项更新：缺失项沿用上一值，每次更新后计算未命中＋缓存读＋缓存写，取所有快照总数的最大值结算。输出仍要求累计不下降。这样缓存分区变化不会仅因分项下降失败，且不低于任一已观察输入总数；部分字段更新可能高估，允许保守多占。每次总数均须在110万内、输出4096内；负数、非整数、未知usage字段/位置、错误/缺失终结、截断、超界、存储失败仍保留全额预留。不是服务商账单，也不证明T011历史unknown原因。

## 固定实验及验收

复用已见ledger/cart合成故障，仅作引导集成回归：明确纠正→真实Agent提案→宿主AST限制写入commit→模型提炼一条候选（先不带citation）→真实工具pytest验证→按真实返回的fact/evidence绑定→关闭来源；新session检查经验适用性、精确应用交付、目标提案、外置pytest及注明基准来源的宿主反馈。模型无shell/任意文件工具，不能改外置验收。完整来源证明及关闭才进入目标。无经验时不伪造交付。不能把测试通过、正常idle或Agent自称成功当闭环。

保留实际失败、数值回执和有限去敏汇总。入口不额外写完整模型事件或stderr正文；实际固定DSH SessionStore仍持久化独立profile的合成会话，关闭session-log不关闭原生会话存储（运行后核实并纠正文档）。仅允许本轮已编写的合成输入，不接入私人真实会话；原生记录、合成仓库/经验库/固定方案/结构化报告仅本机ignored，由owner决定保留和清理。Key仅由官方本地凭据服务加载到内存，不读取或打印正文。旧T011目录/预览profile不变。首次运行后不得修改方案并重新使用资格。

## 限制

付费前独立评审发现只冻结当时列出的文件不足以检测新增conftest；修复复用验证器的`acceptanceDigest`对source/target完整非隐藏Python文件集合递归取摘要。消费资格和每次请求预留前检查，来源/目标实际proof必须匹配冻结摘要；不另写一套扫描规则。原文件逐项哈希继续检查配置/安装/脚本。缺口先保留失败回归，再修复并增量复审。

固定提示、摘要及宿主提交使本轮属于引导流程验证；不是自动提炼、自由代码执行沙箱、未见任务或三组收益评价。真实API模型别名可更新，报告仅记录请求别名与当时官方版本，不能保证服务器实际权重。补充预算不自动授权下一轮。策略只用于实验基础设施，不改变插件/SQLite公开数据格式。
