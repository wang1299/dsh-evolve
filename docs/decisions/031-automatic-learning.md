# ADR031：正常对话的执行片段与自动学习

> 历史设计记录：当时的内部名称按原实现保留。当前身份、路由与升级规则见 [ADR037](037-project-identity.md) 和[安装指南](../installation.md)。

## 用户操作和授权

用户首次设置仓库、Python、仓库外独立验收目录，并明确开启执行、后台验证、经验共享和提炼策略/额度，再开启automaticLearning。默认关闭；缺少前置配置拒绝启动自动模式，不推定旧配置授权新增采集。Agent/面板不能打开开关或改额度。此次实现/演练不改变真实配置，不调用真实模型。

之后正常提出需求和纠正即可。自动建立片段、捕获快照、来源验证、候选提炼、候选独立再验证及适用经验提供。缺材料/漂移/配额不足可见；反馈仍由用户或独立验收证据提供，绝不合成用户认可。

## 任务边界与DSH

固定官方0.2.0-rc.2。agent/pre-step下游允许进入后，只为source.kind=user且非subagent的请求创建片段，标识为session/turn；plugin、goal和重放不补采。片段是一次请求期间的代码变化，不声称是完整语义任务。每轮独立捕获，可以从后续纠正轮的失败状态继续学习，不错误合并不同请求。额外steering只标记归属不确定，不猜测其是否另一个任务。

首步前建立基线；turn/end仅调度固定修复证据处理，cancel/error保留未验证结果。完成/idle/工具运输成功不能认证验收。正常问答没有代码变化时跳过提炼。保留最多256字符去敏请求摘要；只将明确以“纠正：/不对，/Correction:”开头的直接用户文本的最多512字符记为纠正证据，并保存消息标识与摘要。其他自然语言不自动宣称为明确纠正；不保存完整会话、附件或工具输出。

同一仓库同时运行另一个用户片段会使相关自动学习blocked，避免把交错修改当成单一来源。已有显式open任务优先，自动模式不接管它。重复事件由持久唯一键去重。重启未收尾片段和正在执行的候选验证标unknown，不重放、不自动续跑旧用户工作。卸载停止自动协调后再停止已有worker/数据库。

## 未提交快照

在dataDir下的private-snapshots.git保存私有Git对象/提交；用户仓库只执行只读Git命令。使用hash-object/mktree/commit-tree，不写用户index/HEAD/ref，不自动提交、stash或回滚用户代码。

限tracked Python文件和既有依赖描述，最多500文件/8MiB、单文件512KiB；私有store使用128MiB写前水位，超出后拒绝新增。本次最多再写8MiB源码和Git元数据，因此不是磁盘硬配额。忽略/未跟踪文件不采集，出现未跟踪Python、符号链接、submodule或不支持的变更时拒绝自动学习。不复制目录中的其他文件。快照提交SHA属于本地私有对象库，报告明确标注captureMethod、原仓库HEAD和内容摘要，不能冒充用户提交。

捕获前后核对文件集合/内容/依赖/HEAD，不完整或变化即拒绝。独立验证先将两份快照物化到专用目录，运行原始失败、修复后相同验收与回归；验收目录仍须在Agent仓库之外。Python执行保持既有授权边界，不宣称强沙箱。持久快照是复现材料，按现有证据保留，不自动删除；完全遗忘另属G07。模型只接收既有有界去敏diff/事实，无新完整代码上传。

## 数据与后续流水线

SQLite v9增加automatic_segments和协调锁；旧表、旧report格式、unknown、额度原样保留。每片段关联一个Task和私有base/fix、内容摘要、原HEAD、policy摘要、有限状态/原因、消息标识和时间。新程序可读旧记录，旧程序拒绝v9。

EvidenceJobs对自动Task从不可变片段取得两份快照并冻结输入；复用现有耐久Job/Attempt和单次提炼资格。ExtractionJobs在来源/当前代码二次核对后仅生成candidate。automaticLearning的新明确授权允许随后运行独立候选验证：重放测试、检查当前适用范围/全部事实出处/修订号，成功才source_verified；不直接继承提炼前报告为激活资格，不证明策略语义或未来收益。失败/反例/版本变化保持候选或停用。并发验证只有一个持久资格，开始后崩溃不重跑。

正常请求在pre-step已接纳消息中附加至多一条经验的小型DTO，source.kind使用官方可扩展的dsh-evolve-experience，沿用选择算法、共享开关及Application记录；不冒充人类输入，也不唤醒新回合。固定版本先assemble/render动态context再进入pre-step，故该处新增任务不能依赖早已完成的context装配；原候选数量提醒仍使用动态context。提供参考不是模型采用/因果收益。面板显示自动学习进度和缺口，技术快照/处理历史按需展开。

## 验收和限制

先失败用例再实现：未提交修复真实pytest、用户Git不变、篡改/漂移/越界/无变化拒绝、v8迁移、重复/并发/取消/重启、无配额/未授权、明确纠正归属。真实官方AgentLoop脚本provider不调用evolve工具跑通来源→候选→再验证→新请求上下文，实际安装包复验。全check/compat/类型/lint/build及稳定提交独立只读评审、当前头双平台CI后才合并。

每轮快照增加本机成本；复杂跨轮任务不自动语义归并；新建Python文件、非Python依赖资产和非pytest项目有限拒绝。源文件可能含私人文本，去敏不能保证完备，首次开关须明确采集范围。无新增真实模型质量/收益结论；大库、强隔离、完全遗忘和跨平台完整宿主另验。
