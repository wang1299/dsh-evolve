# ADR-007：Codex CLI 本地实验执行器

日期：2026-10-18。状态：采用，兼容性与实际结果单独记录。

## 背景与选择

用户要求继续真实Agent闭环，并明确优先复用本机Codex CLI；不另行索取API密钥。本机CLI为`0.163.0-alpha.10.2`，`codex login status`显示ChatGPT登录。产品仍是DSH插件；新增执行器用于核心经验机制的本地模型实验，不能替代真实DSH模型回合或完整应用安装验证。

使用官方`codex exec --json --ephemeral --output-schema`协议，参数以数组传递、提示经stdin。指定只读sandbox、不加载用户config、不复用旧会话、不加载远端集成。认证由CLI自行读取，程序不读取或复制凭据。沿用CLI默认模型，报告将显式区分请求配置与未观测到的实际模型身份，不将默认别名冒充已冻结模型的三组实验。

传输兼容补充：本机默认WebSocket握手超时；调用级自定义provider `evolve-https`设置`requires_openai_auth=true`、`supports_websockets=false`、`wire_api=responses`，不指定或复制端点与凭据，由CLI使用当前认证方式的默认端点。最小真实模型请求已通过。它不覆盖保留的内置provider，也不修改用户config；执行器默认使用此HTTPS传输，记录transport。可在受信任宿主调用中显式选择CLI默认传输。

## 执行与证据边界

- Codex只读分析合成仓库，返回严格JSON：指定文件的完整修复内容及一条候选经验。运行器检查允许路径、文件原内容摘要和大小，全部检查通过后由宿主写入；不接受任意shell或补丁路径。
- 外部pytest验收不放进提示，也不允许模型写入。宿主验证固定前后Git提交；验收结果与模型自报分开。
- 模型返回的候选没有verified权限；按原有服务流程保存、执行来源验证、检索并记录版本。
- 仅保留命令事件类型、ID、状态和退出码等最小元数据、usage、结构化最终输出摘要、提示摘要及经验版本。原始JSONL、推理文本、任意工具输出和stderr不落盘。
- CLI退出0、turn.completed和最终JSON都不是任务正确的证明。错误JSON、缺少完成信号、超时、取消、资源上限或非零退出均拒绝应用。
- 首轮仅处理本项目生成的合成代码，不将私人会话、用户代码或凭据发给模型。

## 预算和限制

宿主限制每次调用时长、JSONL总字节、单行大小、工具调用数和上下文输入长度，并记录实际token usage。CLI没有在本接口中承诺精确金额或整回合token硬上限；用量在turn完成时才可得，不能将事后统计称为花费硬限制。首个演示最多三次模型调用：来源修复、相似任务baseline、相似任务evolve。两组演示不生成三组已冻结实验报告。

只读sandbox是执行边界；合成代码验证沿用明确受信任代码策略，不宣称完整恶意代码隔离。CLI版本变化需重验事件协议。正常DSH自动工具调用、普通检索组、真实任务集、多次重复及完整应用安装仍属后续T006。

独立评审修正：已知事件结构错误或未知协议事件立即拒绝，不能通过静默忽略绕过预算。超时/取消后请求进程树终止，最多再等待250ms管道清理即失败返回；已经脱离进程组/父进程的后代不在Node宿主的可靠终止能力内，不能声称全部后代已终止。需要处理不受信任或长期后台进程时仍需OS Job/容器等外层运行器。

失败续跑边界：首个HTTPS案例来源修复与baseline通过，evolve调用90秒超时。允许由操作者显式指定本轮合成仓库和失败报告，仅续跑失败的evolve阶段一次，保存新报告并保留原失败。必须核对repoId、干净起点、原经验版本、原提示摘要及验收摘要；不读取旧CLI会话、不重跑已完成阶段。续跑增加evolve预算，结果只证明接入闭环，不能用于等预算收益比较。

续跑评审修正：在调用模型前按原来源验证扫描规则核对整个外部验收Python文件集合和摘要，并以原报告摘要通过`wx`原子创建单次资格记录；同一parent重复/并发调用拒绝。资格一经保留即视为消耗，失败不自动释放。历史未启用资格记录时的尝试另行登记并保留，不删除失败。最终输出契约与宿主必填/数组/摘要约束同步；输出不合格时仅保存字段路径和错误代码，不保留原始内容。
