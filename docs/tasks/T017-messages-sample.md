设计：[ADR020](../decisions/020-single-messages-sample.md)。依赖T016/PR #42，Related #34/#8。用户明确新增最多3元、只取1个真实响应。

## 目标与范围

新准确3元/1请求账本、固定最小官方Messages请求、官方凭据内存解析、T016诊断与本机有限回执；从当前额外字段指纹获得可审查的定位事实。无AgentLoop/用户任务/私人会话或工具，不宣称历史根因/计费兼容/学习收益，不动旧预算或发布。

## 验收

1. 新schema3不能被旧/默认构造混开，预算/回执版本/1次限制保持；结算或重启也不允许第二次预留。
2. 项目根锚定新方案/账本，计划及源码摘要、一次资格在发网前验证；冻结后不改题/重跑。
3. 真实凭据只经官方服务在内存使用，probe只describe；离线rehearsal为fake key/transport且无真实服务商调用。
4. 仅一次真实HTTP；正常/未知/失败都保留有限数值与结构回执，未知不退还，原始响应不落盘；无匹配/截断如实未知。
5. 付费前独立稳定SHA审查、离线必要测试/类型/静态/构建，最终结果核对及当前头两平台CI/兼容和实际包检查后合并。
