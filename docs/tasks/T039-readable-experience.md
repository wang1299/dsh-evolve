# T039：面向使用者的经验页面

Issue [#91](https://github.com/wang1299/dsh-reforge/issues/91)，分支 `codex/t039-readable-experience`，基线 `797e8f261ceb76800caab146ddcf989745e25ff2`，设计 [ADR038](../decisions/038-readable-experience.md)。

用户指出当前记录不直观、像后台信息。目标是让使用者直接理解当时的任务、留下的提醒、修复检查和后续参考；原文、测试明细及管理按需展开。不能通过美化界面创造中文翻译、采用事实、业务示例或收益证明。

范围：共享面板及宿主主题、只读展示投影、相关回归和产品/架构验收说明。不改数据库、API、模型提炼、预算/授权和私人安装。新界面在独立合成预览及隔离实际宿主中验收。

验收：先保留旧界面无法满足故事主标题/原文分层的失败断言；验证缺失/候选/停用/超时/跳过/未知反馈不会误报通过或收益，内容安全、草稿/轮询/冲突/历史版本保持；类型/静态/构建、完整测试/兼容、实际包审计/安装、桌面/窄屏和明暗主题交互；稳定 SHA 独立只读评审及当前头 CI/仓库规则后合并。实际结果记入本任务验收记录和 Issue/PR，未执行不计完成。

实现、失败复现和实际检查见 [T039 验收](../development/T039-acceptance.md)；最终当前头评审、CI、实际包界面和交付结果以本 Issue/PR 为准。本轮零模型调用，原用户环境不自动升级。
