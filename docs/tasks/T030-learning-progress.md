## 范围与顺序

1. 只读配置/额度及逐任务四阶段进度投影，固定原因与下一步。
2. 主页展示学习配置与近期处理卡片，直接打开候选，保护现有编辑。
3. CLI panel 启动既有自动协调器，补齐已授权候选的独立复核。
4. 失败复现、针对检查、完整检查/兼容、实际包、浏览器、独立评审、修复和最终 CI。

不新增模型调用/预算、授权写入、自动重试或数据格式；不改变原实验结论。DSH 原生界面嵌入另拆任务。
