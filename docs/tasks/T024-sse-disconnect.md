# T024：SSE 消费者完成后关闭连接

Issue：[#57](https://github.com/wang1299/dsh-evolve/issues/57)；设计：[ADR026](../decisions/026-sse-consumer-disconnect.md)。

## 目标与范围

避免合法客户端读完终端帧后的响应释放，被转发器自身转化成未知费用。只修改实验预算 HTTP 收尾和必要回归，不更改插件公开工具、学习库或来源验证。

## 验收

1. 离线复现：完整 SSE 后消费者取消、上游稍后正常 EOF，旧实现保留 unknown，新实现在严格完整回执后结算。
2. 终端帧前取消仍中断并保留预留。
3. 终端后上游错误、额外事件、响应边界与持久化失败不释放未知占额。
4. 原账本与旧 unknown 保持原样，不依靠新付费请求验收。
5. 类型、静态、构建、针对预算测试及必要 CI、稳定 SHA 独立只读评审通过。

依赖 T013/T018。Windows 运行目录准备、真实模型学习和收益评价单独记录，不能用本任务的离线结果宣称完成。
