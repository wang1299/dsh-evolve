# T006c：三组初步对照执行

关联Issue #8的执行／证据子任务。原基线3caf90b，原分支codex/t006c-paired-evaluation保留。用户已恢复GitHub开发，当前codex/t006c-remote交付七个已审文件；远端检查／评审在PR登记，父Issue仍未完成，不关闭。

目标：将已有Codex接入变为可冻结、可检查且保留失败的三组运行，不编造CLI未支持的控制。

范围：模型/推理控制、共同提示/任务摘要、v2评价格式和旧v1兼容、三组选择、源经验重放、一次性运行资格、可选真实合成对照。非目标：真实DSH模型、正式收益宣称、发布、操作参考仓库。

验收：

1. 显式模型名与推理档位传入CLI并进入证据；不可控temperature/seed/revision及token硬限明确为null。
2. v1仍可读取，v2拒绝跨组控制差异、泄漏、缺组、重复、无效验收与基线注入；失败和未知不能当成功。
3. retrieval与evolve策略分别实现；冻结经验库，评估反馈不会回流其他组。
4. 源经验在新仓库重放并重新验证，保留来源映射；三组相同起点及外部验收，无模型工具调用被接受。
5. 运行前原子保留资格，单组失败不丢失后续组，崩溃不自动重试；报告不上传私人数据。
6. 类型/静态/构建、针对测试、一次小规模真实执行及稳定提交独立只读评审；实际尚未验证部分明示。
7. 报告提供经验的实际次数；全部拒绝注入时明确不能评价经验收益。该合成配方后续缺少经验暴露时，调用前终止，不自动重跑首轮结果。

依赖T002、T005、T006b；设计ADR-008。每组默认一次90秒，首个实跑共3次模型调用，无自动重试。
