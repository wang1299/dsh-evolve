# T015：真实DSH学习回归

## 问题与目标

T011在错误citation/未知用量预算处失败。T012–T014已离线修复并验证编排；本轮用用户新授权5元检查真实模型闭环。设计见[ADR018](../decisions/018-supplemental-live-validation.md)。依赖T012/T013/T014及完整官方DSH0.2.0-rc.2和本机已配置Key。

## 范围与非目标

新账本/资格/profile/固定方案、保守快照计数、零模型握手、一次真实引导回归与可审查的去敏证据。无发布、无原账本调整、无自动重跑或普遍收益结论。

## 验收

1. 旧策略/账本哈希不变，新策略账本不可用旧程序打开；未知/崩溃/磁盘异常不释放。
2. 缓存重分配以最大输入总数计，输出累计/未知位置/终结/超限保护保留，合成HTTP与重启失败用例覆盖。
3. 新方案/安装/配置/源代码身份检查、固定项目路径及一次资格；零模型握手后付费前稳定SHA独立只读评审。
4. 实际仅一次live，最多16请求/5元，来源与目标外部pytest、事实引用、任务关闭及实际交付分别报告；失败记录保留。来源成功不能替代目标/收益。
5. 类型/静态/针对检查、必要完整check/compat、两平台CI与实际tgz安装，结果文档一致及必要增量复审后才合并。

## 公开与本地

公开仅合成聚合结果和文件摘要；固定方案、凭据、学习库、报告本机ignored。Issue/PR编号与实际检查状态写入验收记录；初始状态为待实现/待真实运行。
