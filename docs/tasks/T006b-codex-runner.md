## 验收

1. shell:false、stdin提示、只读sandbox、独立临时回合；认证不经程序读取或输出。
2. 使用真实本地子进程的确定性协议fixture验证合法结果、非零退出、失败/缺失完成、错误JSON、工具上限、超时/取消、路径越界/过期内容和上下文上限；fixture不称真实模型。
3. 模型没有直接写权限；宿主只应用允许文件且原内容摘要匹配的结构化修复。
4. 可选实跑用真实Codex生成来源修复和候选；来源失败/修复/回归有独立pytest证据；第二任务记录实际提供的经验版本。
5. baseline与evolve从同一目标提交开始；失败及无改善照实记录，token和未知成本分开。
6. 不可用或模型调用失败时保留最小失败报告；不伪造通过、不换无隔离模式兜底。
