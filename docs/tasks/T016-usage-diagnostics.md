# T016：安全可定位的Messages诊断

Issue [#41](https://github.com/wang1299/dsh-evolve/issues/41)，Related #34/#8。依赖T013最小数值回执与T015真实失败。设计见[ADR019](../decisions/019-usage-shape-diagnostics.md)。

## 目标、范围及非目标

为相同unsupported_usage提供固定位置/原因和有限未知字段指纹；显式新回执格式接入离线HTTP，旧格式/预算/历史保持。不忽略未知计费字段、不追加付费、不认定历史根因，不改变插件API/SQLite或发布。

## 验收

- 五类拒绝位置可区分，非对应原因不伪造diagnostic；已知计数/完整流的判定及v1返回形状不变。
- 未知字段仅最多8个稳定指纹及数量，不落原名、值或任意消息；严格schema/截断信息可解释。
- 默认仍写v1；v2显式选择，只给当前实例新预留写回执。v1/v2统一可读，不修改旧字节或由诊断退还unknown。
- 合成本机HTTP证明诊断有因果关联、失败保留全额预留、重启不能补造；预算/终结/磁盘故障既有回归通过。
- 必要类型/静态/构建/核心检查与DSH兼容、文档同步，稳定提交独立只读评审/必要修复复审、当前头CI通过后PR合并。

## 状态

设计/失败用例后实施。真实采样和协议兼容仍在#34，产品完整学习及收益在#8/#15；本轮只进行离线开发与合成测试。
