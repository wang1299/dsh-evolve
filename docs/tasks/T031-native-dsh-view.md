# T031 DSH 原生经验入口

分支 `codex/t031-native-ui`，基线 4dd2f14。依赖 T028–T030，设计 ADR033。

## 范围

原生插件设置页、对话顶部入口和主面板，复用单仓库经验界面和已有 API。共享 EvolveService，通过官方认证 RPC，无额外服务或 token；既有管理行为不扩权。保留独立面板。不增加付费调用、自动学习授权、预算或配置向导。

## 验收和顺序

1. 设计提交，必要失败用例。
2. 共享 API、受限 RPC、client bundle 和槽位生命周期。
3. 针对/类型/静态/构建、实际包与完整固定 Web 验证。
4. Draft PR、独立只读评审、修复与最终 CI 后合并，更新自己的测试安装。

原生入口应能在 DSH 内查看学习进度、来源、经验与使用记录，打开/返回/重启有效；冲突、断连和超时保留编辑，不重放写入。单仓库归属、operator 认证、请求大小和卸载均须检查。SQLite/原经验/授权/用户代码保持原状。实际结果另记验收文档。
