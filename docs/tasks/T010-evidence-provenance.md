# T010：经验事实来源与保留

Issue [#29](https://github.com/wang1299/dsh-evolve/issues/29)，依赖T009 / G01+G07。[ADR013](../decisions/013-fact-evidence.md)先于实现提交。

范围：最小纠正/验证证据、revision事实引用、摘要/归属校验、默认资格、保留历史的事务迁移（v1降级重验/v2不改写）、引用清理保护、六工具与本机面板。非目标：自动采集归并/提炼、Job、上下文预算、沙箱、收益实验、发布。

验收：真实Git/pytest纠正→修复→引用→后续复用→清理仍查来源；缺失/错误归属/摘要/重复/越界/stale拒绝且无半写；验证/停用/修订/恢复保留正确历史；相同来源保存幂等，完整已验证来源锁定，不因来源元数据更新绕过负反馈；v1/v2升级不丢旧数据；生产默认拒绝缺事实来源，冻结实验仍用原策略；官方DSH/面板/迁移/包安装及两平台当前头CI通过，独立SHA评审闭合阻塞。

计划步骤：设计与失败复现→数据/服务及迁移→DSH/面板→相关测试与文档→Draft PR→独立只读评审→修复/复审→CI与规则→squash。实际结果记入本任务验收和PR，未来步骤不标已完成。
