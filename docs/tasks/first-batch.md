Codex执行器子任务见[T006b](T006b-codex-runner.md)。用户已恢复GitHub开发，当前任务仍按聚焦交付和条件合并推进。

这些是本地任务编号，不是 GitHub Issue 编号。远端就绪后逐项创建 Issue 并填写链接。

## T001 需求与开发基线

目标：固定本会话产品目标、MVP、持久化与接口设计、验收和流程。
范围：README、需求、架构、ADR、路线、任务与PR模板。非目标：实现产品或发布。
验收：五模块和八项MVP验收可追踪；修复与收益验证分开；未知状态如实标记。
依赖：无。验证：文档链接和独立只读设计评审。

## T002 可执行经验闭环核心

目标：真实 pytest 失败／修复／回归证据驱动经验验证和复用。
范围：类型与SQLite、隔离回放、提取候选、作用域检索、应用反馈、修订停用恢复、合成目标仓库集成。
非目标：模型训练、泛化收益声明、任意验证命令自动执行。
验收：A1-A5；基线错误／空测试／非测试失败不能验证；跨仓库和条件变化不选；无效反馈拒绝；历史可恢复但需重新验证。
依赖：T001。必要验证：边界单元测试、真实临时 Git/pytest 集成、类型／lint／build。

## T003 DSH 原生适配

目标：固定版本工具和提示区在真实官方服务工作。
范围：Bundle、工具、事件元数据采集、上下文选择、取消及卸载清理。
非目标：改DSH核心、用fake Context宣称兼容、无凭据真实模型调用。
验收：A7；类型来自固定npm包；真实服务注册／执行／卸载探针；未验证范围明示。
依赖：T002。验证：固定发行包运行探针与相关回归。

## T004 面板与主流程

目标：用户可查看经验、来源、状态、历史并执行修订停用恢复。
范围：本地面板、鉴权与来源检查、合成闭环演示。
非目标：云同步、公开服务、多用户平台。
验收：A6；无任意文件读取／命令执行接口；未认证和跨站写入拒绝；输出转义；主流程证据可复现。
依赖：T002,T003。验证：HTTP集成、浏览器检查与合成案例。

## T005 对照评价

目标：可导入三组实际结果，检查比较条件并报告缺失和失败。
范围：评价输入与报告。非目标：用脚本固定答案冒充真实Agent实验。
验收：A8；不一致模型、预算、环境、任务、验收和数据泄漏需报错；缺失不是成功。
依赖：T002。验证：正反结果集与合成报告。

## T006a 安装包配置层修复与探针

问题：官方安装实际tgz后，原manifest只覆盖不存在的行，组合结果为空。
目标：安装包确实为DSH贡献插件条目。
范围：insert manifest、官方配置层回归、按需运行的隔离profile tgz安装探针及证据。
非目标：完整Web/Desktop安装、真实模型运行、发布npm/Release。
验收：旧manifest断言失败，修复后通过；官方共享安装操作成功、无跳过bundle、组合含唯一插件条目；现有服务探针继续通过。
依赖：T003,T004,T005的已修复本地分支。必要验证：manifest回归、真实tgz安装、类型/lint/build和受影响兼容测试、稳定提交独立只读评审。
